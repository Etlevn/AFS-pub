# Security

Never include credentials, private reports, account identifiers, or local
configuration in public issues or pull requests.

Report suspected vulnerabilities through GitHub private vulnerability reporting
on this repository's Security tab. If that option is unavailable, do not disclose
sensitive details in a public issue; ask the maintainer to enable a private channel.

If a credential is exposed, revoke or rotate it at its provider. Removing the
credential from a file or Git history does not invalidate the credential.

The project produces research and trading plans. It does not place broker orders.
Review data quality and model output before using it in an execution system.
